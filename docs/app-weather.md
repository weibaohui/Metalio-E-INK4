# 天气（weather）

墨水屏「第二屏」的经典形态：**七段数码管大温度 + 三天预报**，一天刷几次、静默待着，还能点一下让机器把天气念出来。

![图标](../tools/weather_app/icon.png)

![天气真机截图](screenshots/weather.png)

## 界面

| 区域 | 内容 |
|:---|:---|
| 顶部 | 城市名 + 城市本地观测钟点 |
| 中部 | **七段数码管大温度**（只画点亮的段）+ 纯几何天气图标（太阳/云/雨/雪/雷/雾全是几何拼的） |
| 指标 | 天气描述 / 体感温度 / 湿度 / 风速 / 降水概率 |
| 下半 | 今天 · 明天 · 后天三天预报（现象、最高/最低、降水概率） |
| 底部 | 更新时间、数据源 + 三个按钮：**城市 / 刷新 / 朗读** |

## 亮点

- **城市选择面板**：353 个城市（全国地级市 + 港澳台），底部 A–Z 字母条按拼音首字母过滤 + 分页，含生僻字城市（亳、儋、淖、滁、漯、菏、郴已补进字库）
- **熄屏朗读**：点「朗读」用固件 TTS 播报天气——不烧屏、不耗刷新电，墨水屏独占能力
- **断网不白屏**：上次读数缓存在沙箱 `data/weather.txt`，先显示缓存再静默更新
- **数据源**：[Open-Meteo](https://open-meteo.com/)，免注册免 key；经固件 `dynapp_http_get_async` 走证书链 HTTPS（响应 ≤16KB）

## 墨水屏上的讲究

- **值没变就不刷**：自动 30 分钟刷新一次，数据一样直接跳过——每刷一次都在老化
- 七段数码管灭掉的段完全不画，1bpp 上留空心框只会把字形搞脏
- 联网前用 `dynapp_sysinfo_get` 预检内存（HTTPS 握手要 14KB 连续内部 RAM），不够就等会儿再发

## 配置

进阶用户可放 `data/cities.txt` 自定义城市、`data/config.txt` 调刷新间隔，格式见 [`tools/weather_app/README.md`](../tools/weather_app/README.md)。
