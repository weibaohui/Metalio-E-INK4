# 唐诗宋词（poems）

随身诗词库：内置 **1092 首**唐诗宋词 + **41 篇赏析**，每日一诗、随机通读、收藏夹、书目浏览，全部离线。

![图标](../tools/poetry_app/icon.png)

![唐诗宋词真机截图](screenshots/poems.png)

## 它能做什么

- **每日一诗**：按日期种子选诗，开机读一首
- **随机一首**：LCG 序列防短期重复
- **书目浏览**：唐诗三百首 / 宋词三百首 / 千家诗 / 诗经 四个诗集 + 课本讲解与诗话 + 词牌故事
- **收藏夹**：好诗标星单独翻
- **赏析页**：部分诗挂讲解（课内讲解 / 独立赏析 / 词牌故事三类），「◀ 原诗」一键跳回

## 界面与操作

- 首页：大标题 + 2×2 大按钮（每日一诗 / 随机一首 / 书目浏览 / 我的收藏）
- 诗页：居中标题（30 号粗体）+ 作者 · 朝代 · 体裁 + 逐行居中正文 + 页指示（有赏析时提示「有赏析」）
- 盖板 `vk_next` / `vk_prev` 翻页，翻到头自动切下一首 / 上一首
- 底部按钮：收藏 / 赏析 / 随机 / 书目

## 数据与补字工程

- 数据库 `poems.db`（约 292KB）随包内置，由 [`tools/poetry_pack/pack_poems.py`](../tools/poetry_pack/) 打包：语料取自开源 chinese-poetry 库转简体，逐条 zlib 压缩
- **生僻字补字**：扫描全部语料得 1186 字补字集，合并进 Flash `font_data` 分区 30@2 字档——分区仅剩 ~257KB 预算，预算外含生僻字的诗经篇目整首剔除，保证**正文零缺字**
- 收藏与进度存 `data/state.txt`

## 墨水屏上的讲究

语料统一 30@2 字号渲染（补字只烧这一档）；单条解压单条驻留；全零初始化静态变量规避加载崩溃。
