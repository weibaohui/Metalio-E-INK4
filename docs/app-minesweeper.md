# 扫雷（minesweeper）

回合制扫雷，9×9 盘三档雷数，长按插旗，一步一刷。

![图标](../tools/minesweeper_app/icon.png)

![扫雷真机截图](screenshots/minesweeper.png)

## 界面与操作

- 9×9 盘 450px（与数独同布局语言）；右上「难度 · 雷 X · 旗 Y」
- 点格子翻开（已翻开的数字格支持 chord 连开）；**长按插旗**；「插旗模式」切换后点格 = 插旗
- 三档难度 = 10 / 15 / 20 雷
- 首点保证不踩雷（布雷时挪走首点）；flood fill 展开空白；踩雷翻出全部雷
- 底部三键：**新游戏 / 难度 / 插旗模式**

## 1bpp 的数字与图形

- **数字双编码**：数字 + 下方点阵（像扑克牌点数，≤4 一行、>4 两行）——1bpp 没颜色，双保险看得清
- 旗 = 旗杆 + 三角旗；雷 = 中心块 + 四向臂 + 四角点的几何八角形，零字体依赖
- 未翻开格带 2px 边框表示「未揭」，翻开后去框
