# 阅读（book）

内置电子书阅读器：**书库 → 详情 → 正文**三段式，配合阅读统计首页，是这台墨水屏设备的本职场景。

![阅读首页真机截图](screenshots/book.png)

## 阅读首页

- 左侧「**继续阅读**」黑卡：当前书阅读百分比 + 进度条，一键回到上次读到的位置
- 右侧「**阅读数据**」：累计阅读时长、已读完本数（装饰柱图）
- 「**最近阅读**」两格封面（书封面旁路文件 `.a2i1`，无封面自动占位）
- 底部「我的书架 >」进入书架

## 书库与格式

- 书库目录：SD 卡 `/sdcard/metalio/e-ink/books/`
- 支持格式：**`.ebook`**（专用格式）、`.epub`、`.txt`
- 书架每页 3×3 封面，按文件时间排序，支持勾选删除
- `.txt.idx` 分页索引、`<书名>.pos` 进度边车、`.a2i1` 旁路封面，均自动生成
- 云端推送的书（传输 / WiFi 传书）会自动落入书库并触发重扫

## 正文阅读

- 页脚：章节名 + 当前页 / 总页 + 百分比
- 翻页：触摸左 1/3 上一页、右 2/3 下一页；盖板 `vk_prev` / `vk_next`；音量键（侧边）也可翻页
- 长按虚拟键连翻；**列表与正文禁止滚动**——墨水屏拖动留残影，翻页一次刷一屏反而干净

## 阅读设置（书内面板）

| 项 | 内容 |
|:---|:---|
| 字号 | MIN ~ MAX 多档 |
| 页边距 / 行距 / 段距 | 排版微调 |
| 字体 | `.ef` 矢量字体列表，放 SD 的 `fonts/` 目录；「导入 TTF」可把 `fonts_ttf/` 里的 TTF 现场转成 `.ef` |
| 下划线 | 划线样式 |
| 目录 | 整页分页显示章节，当前章加粗定位，点击跳章 |
