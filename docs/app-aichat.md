# AI 对话（aichat）

内置语音助手：**按住说话 → 云端语音转文字 → LLM 流式回答 → TTS 播报**，整条链路走流式，墨水屏只在一轮结束时刷新。

![AI 对话真机截图](screenshots/aichat.png)

## 界面与操作

| 区域 | 内容 |
|:---|:---|
| 标题行 | 「AI 语音对话」+ 自动发声开关 + 设置齿轮 |
| 状态行 | 按住说话 / 录音中 / 识别中 / 思考中 / 播报中 / 出错 |
| 对话区 | 「我：」识别文本与「AI：」回复，可翻页回看 |
| 底部 | 「按住说话」大按钮 + 「停止」按钮 |

- **按住说话，松开发送**：按住开始录音，松开即送 ASR；短于 300ms 视为误触自动取消
- **停止键**：随时打断——录音 / 转写 / 流式输出 / 播报一律立即终止归位
- 播报中再按住说话 = 打断播报，直接录新一句
- 回看对话：触摸滑动或盖板 `vk_prev` / `vk_next` 翻页，长按跳开头 / 结尾

## 语音播报设置

设置弹窗里可调：**音色**（默认 `male-qn-qingse`）、**语速**（0.8x ~ 1.5x）、**情绪**（自然 / 欢快 / 低沉 / 严肃）、**合成音量**；「自动发声」开关控制是否 TTS 念出回复。

## 服务配置

- 云端走 MiniMax 三件套：STT（`speech_to_text`）+ LLM（`MiniMax-M3.1-Flash-Preview`）+ TTS（`t2a_v2`）
- API Key 不在屏幕上配置，经设备 MCP 工具 `self.aichat.configure` 下发（见 [`docs/app-store.md`](app-store.md) §8）
- 未配 Key 时按住说话会给出提示
- 会话记录落 SD 的 `chat_log/`（开机清空，超 512KB 轮转）

## 墨水屏上的讲究

- 对话流式输出期间屏幕保持安静，**一轮结束才刷一次**——墨水屏刷太快只会留残影
- 熄屏朗读是独占能力：TTS 播报不依赖屏幕，退屏后声音照样走（I2S 经外置蓝牙音频芯片出声）
