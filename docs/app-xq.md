# 中国象棋（xq）

完整规则的中国象棋：**全部走法 + 将军 / 将死 / 困毙判定 + 飞将禁着**，本地双人换边对坐，一步一刷。

![图标](../tools/xq_app/icon.png)

![中国象棋真机截图](screenshots/xq.png)

## 界面与操作

- 9×10 线棋盘（格 45px、棋子 40px），九宫斜线用点串画，河界「楚河 / 漢界」
- 点己方棋子选中（方框标记）→ 点目标点落子；再点自己 = 改选 / 取消
- 底部四键：**新局 / 悔棋 / 提示 / 选边**
  - **提示**：显示选中棋子所有合法落点（圆圈标记）并报可走点数
  - **选边**：切换你执空心方还是实心方，界面常驻显示「你执 X 方」
- 将军时弹出「将军！」提示；将死 / 困毙判负并说明原因
- 存档自动落 `data/xq.txt`，重进续盘

## 1bpp 上的红黑之分

墨水屏没有颜色，「红方 / 黑方」传达不了信息，改用**明暗阵营**：

- **空心方**：白底黑字（帥仕相馬車炮兵，先行方）
- **实心方**：黑底白字（將士象馬車炮卒）

界面文案一律写「空心 / 实心」，不写「红 / 黑」。

## 墨水屏上的讲究

- 九宫斜线画不了——固件未导出 `transform_rotation`，用点串拼斜线
- 走一步只重绘起点 / 落点两个棋子 + 最后手标记；每 10 步全刷去残影
- 空闲 3.5 秒落盘、6 秒全刷
