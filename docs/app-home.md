# 桌面与待机（home / standby）

桌面是设备的门面：**大时钟 + 应用宫格**，所有内置应用与动态应用都在这里出现；待机画面则是墨水屏「常显」形态的载体——息屏不断电，一幅画挂在那儿。

![桌面真机截图](screenshots/home.png)

## 桌面

| 区域 | 内容 |
|:---|:---|
| 状态栏 | Wi-Fi、时间、电量（所有屏幕顶部常驻） |
| 大时钟区 | 160 号大字时分 + 日期 / 农历 / 天气行（无天气数据自动隐藏整行） |
| 应用宫格 | 每页 3×3 = 9 个应用卡片（70px 图标 + 名字，名字超 4 字截断） |
| 页码指示 | 底部圆点，实心为当前页 |

- **翻页**：左右滑动手势，或盖板 `vk_prev` / `vk_next`（支持长按连翻）
- **卡片样式**：白底 / 网点灰 / 黑描边三种，在「设置 → 主题」切换——网点灰用的就是 Bayer 抖动（见 [`docs/epd-bayer-dither-gray.md`](epd-bayer-dither-gray.md)）
- 应用可见性由 AppManager 统一管理：内置 6 个 + 动态应用按安装标志注册，个别必选应用不可关

## 待机画面

空闲一段时间（「设置 → 功耗」可调，默认 3 分钟）进入浅睡待机，墨水屏保留一幅静态画面：

- **壁纸形态**：「待机壁纸」应用选过图 → 全屏壁纸常显
- **经典形态**：日期 + 农历 + 天气 + 猫咪吉祥物气泡
- 待机中吞掉所有盖板键（防误触）；按 **POWER 短按**唤醒
- 关机画面同理：优先用户指定的关机壁纸，否则用固件内置关机图

## 待机时还能显示什么

- 「挪车电话」可以把号码生成成待机壁纸——息屏状态就是一块挪车牌（见 [`app-parking.md`](app-parking.md)）
- 天气 / 时钟数据由固件缓存，待机页免联网直接显示
