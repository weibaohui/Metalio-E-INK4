# 知识卡片（knowledge）

把整座个人知识库装进墨水屏：内置卡片数据库（实测 **4.4 万卡**），按卡解压、按需驻留，卡片间 `[[链接]]` 互相跳转——一台脱离手机的「离线 Anki」。

![图标](../tools/knowledge_app/icon.png)

![知识卡片真机截图](screenshots/knowledge.png)

## 它能做什么

- **卡片视图**：标题 + 章节行 + 正文分页（正文超高自动分页），尾部「—— 关联 ——」列出 `[[卡名]]` 链接，点按即跳转
- **每日一卡**：按日期哈希选卡，每天开机看一眼
- **随机**：随机抽卡复习
- **收藏**：标记好卡，收进收藏夹单独翻
- **书目**：两级书目浏览——书库分类（collection）→ 书组（book），显示「x 书 / y 卡」统计，可进某书列表逐卡看

## 操作

- 盖板 `vk_next` / `vk_prev` 翻页：正文末页再往后自动翻到下一张卡，首页再往前翻到上一张卡
- 底部按钮：收藏 / 每日 / 随机 / 书目
- 屏上不画翻页按钮——翻卡统一走侧键，避免墨水屏频繁刷新按钮区

## 数据与更新

- 数据库 `cards.db` 放在应用沙箱 `data/`，由 [`tools/knowledge_pack/pack_cards.py`](../tools/knowledge_pack/) 从 Markdown 卡片库打包（zlib 按卡压缩，A/B/C 三种卡格式，collection→book 两级分组）
- **更新 = 重新打包 + 替换 `data/cards.db`**，重装应用不丢库
- 进度与收藏存 `data/state.txt`

## 墨水屏上的讲究

- **按卡解压**：固件导出 `dynapp_zlib_inflate`，读哪张解哪张，PSRAM 只驻留单卡——4.4 万卡的库也只占几 KB 内存
- 全文件静态变量强制零初始化，规避 elf_loader GOT 重定位加载崩溃（动态应用 C 开发的著名坑）
