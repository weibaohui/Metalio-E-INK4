# 纸牌接龙 动态应用（sol）

经典纸牌接龙（Klondike），回合制、一步一刷，适配墨水屏低刷新率特性。

![界面](../docs/mockups/cards-gray-sol.png)

## 界面

| 元素 | 画法 | 为什么 |
| --- | --- | --- |
| 暗牌（牌背） | **25% 网点浅灰** + 1px 黑框 | 1bpp 没有真灰，用 Bayer 抖动模拟 |
| 红花色（♥♦）明牌 | **黑底白字** | 1bpp 没有红黑之分，只能用明暗分阵营 |
| 黑花色（♠♣）明牌 | 白底黑字 | 同上 |
| 点数 | 18@2 | 字体包里现成 |
| 花色 | 30@2（♠♥♦♣） | 字体包里现成 |

> ⚠ **牌背原来画的是实心黑牌**：牌堆一压就是一大片死黑，又丑又费墨
> （墨水屏大块纯黑局刷留灰影、刷新也慢）。换成网点浅灰后清爽很多。

## 网点灰的坑（改牌背前必读）

- 实心区域用 `gray_dither_fill(obj, GRAY_DITHER_MID)`（见 `tools/_shared/gray_dither.h`）。
- **翻回正面时必须用 `gray_solid_fill(obj, ...)` 撤掉网点**。
- ⚠ **画成牌背后要让 `s_rendered_card[id]` 缓存失效**（置 0xFF）：
  `render_card()` 开头有"样式没变就直接 return"的缓存，牌从正面翻成暗牌、
  再翻回正面时样式值一样 → 缓存命中 → `render_card()` 直接返回 →
  **牌背的灰底撤不掉，牌一直是灰的**。牌背是灰的、正面也是灰的，看起来像 bug。
- 网点**相位以对象自己的左上角为原点**，每张牌相位不同，正常。

## 内存

52 张牌常驻 52 个对象 + 各自 2 个标签；移动时只重排受影响的 1~2 个堆 → 脏区小，局刷快。

## 构建 / 部署

```bash
./tools/package_app.sh tools/sol_app
./tools/package_app.sh tools/sol_app --upload <IP> --pin <PIN>
```
