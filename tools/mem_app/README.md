# 记忆翻牌 动态应用（mem）

回合制翻牌配对，一步一刷，适配墨水屏低刷新率特性。

![界面](../docs/mockups/cards-gray-mem.png)

## 界面

| 元素 | 画法 | 为什么 |
| --- | --- | --- |
| 暗牌（牌背） | **25% 网点浅灰** + 2px 黑框 | 1bpp 没有真灰，用 Bayer 抖动模拟 |
| 翻开的牌 | 白底 + 黑字 + 2px 黑框 | 纯黑/纯白才最清楚，一眼能和牌背分开 |
| 已配对 | 黑框加粗到 3px | 不加额外符号，免得 1bpp 下糊成脏点 |

> ⚠ **牌背原来画的是实心黑牌**：一屏 16 张 90×120 的黑牌 → 整屏 43% 是死黑，
> 又丑又费墨（墨水屏大块纯黑局刷留灰影、刷新也慢）。换成网点浅灰后整屏黑色
> 占比降到 15%（剩下的基本都是牌框），清爽很多。

## 网点灰的坑（改牌背前必读）

- 实心区域用 `gray_dither_fill(obj, GRAY_DITHER_MID)`（见 `tools/_shared/gray_dither.h`）。
  别拿网点去画**细线/描边**——1bpp 下细线的网点会被抖没；网点底上的**黑**线会消失，
  要看得见得用**白**色。
- 网点**相位以对象自己的左上角为原点**（`lv_draw_image_tiled_helper` 从对象原点开始铺），
  每张牌的相位都不同——这是正常的，不是 bug。
- 翻回正面时要用 `gray_solid_fill(obj, ...)` 把网点撤掉，否则牌还是灰的。

## 牌面符号

用字体包里现成的 8 个字形：♠♥♦♣ A J Q K（30@2 都有）。不要自己画几何图形，
字体包的字形边缘更干净。

## 构建 / 部署

./tools/package_app.sh tools/mem_app
