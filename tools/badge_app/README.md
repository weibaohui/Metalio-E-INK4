# 电子工牌 动态应用

挂在前胸 / 摆桌上的身份卡：**大头像 + 大字**，让人隔着半米也能看清你是谁。

![界面](icon.png)

## 和「电子名片」分工

| | 电子工牌 | 电子名片 |
|---|---|---|
| 场景 | 挂着看 | 递出去交换 |
| 重点 | 头像大、名字大、一眼看清 | 身份 + 多个码入口 |
| 码 | 一张（够扫就行） | 多张，标签切换 |

## 界面

```
┌──────────────────────────────┐
│        电子工牌        1/2    │
│                              │
│         (大头像)              │
│                              │
│          神经蛙               │
│          产品经理              │
│      示例科技 · EMP-1024       │
│ ──────────────────────────── │
│      ┌───────────────┐        │
│      │               │        │
│      │     码        │        │
│      │               │        │
│      └───────────────┘        │
│        13800000000            │
│        frog@example.com       │
│        今天也在搬砖            │
│ [上一张][下一张][重载][怎么改]  │
└──────────────────────────────┘
```

- 全部居中排版 + 大量留白：工牌是「看」的，不是「读」的
- 层级：姓名 30@2 > 职位 25@2 > 公司/联系方式 灰色 25@2，一条细线分段
- 底部只放一行小按钮，主区域只放身份

## 配置

`profile.txt` 放 app 自己的 `data/` 目录：

```ini
[card]
name=神经蛙
title=产品经理
company=示例科技
dept=产品部
id=EMP-1024
phone=13800000000
email=frog@example.com
url=https://folotoy.com
status=今天也在搬砖
avatar=avatar.png

[card]
name=李四
title=技术总监
company=示例科技
...
```

- 多个 `[card]` 段就是多张工牌，用「上一张 / 下一张」或硬件上下键切换
- 头像放 `data/avatar.png`（或用 `avatar=` 指定别的文件名），没有就画「圆圈 + 姓名首字」占位
- 码：优先用 `[qr]` 段的第一个；没有就拿 `url`（或精简 vCard）生成

## 怎么传上去

```bash
curl -X POST \
  -H "Authorization: Bearer <PIN>" \
  -H "X-Filename: profile.txt" \
  --data-binary @profile.txt \
  "http://<设备IP>:8080/fs/upload?path=apps/badge.app/data"
```

改完点「重载」生效。

## 按键

| 键 | 动作 |
|---|---|
| 触摸「上一张 / 下一张」 | 切换工牌 |
| 硬件上/下键 | 上一张 / 下一张 |
| 硬件 Home 键 | 返回桌面 |
